# Gachara

A Windows companion app for gacha games: one tier list built from the best
guide sites, your box synced from your account, and advice on who to use and
who to upgrade, based on the characters you actually own.

Formerly called Gachadex: copies installed under the old name update to
Gachara by themselves and keep all their data.

## Download

Get the latest installer from [Releases](https://github.com/Axel3614/gachadex-releases/releases/latest)
(`Gachara-Setup-<version>.exe`) and run it. Installed copies update by
themselves.

The installer isn't signed yet, so Windows SmartScreen asks for confirmation
the first time: "More info" → "Run anyway".

Gachara is free, with no ads and no account. If it helps you, you can
[support it on Ko-fi](https://ko-fi.com/axel394).
